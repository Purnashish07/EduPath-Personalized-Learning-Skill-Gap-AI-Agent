# EduPath Voice-over Script

**Target delivery:** professional, friendly English technology presenter; moderate pace, clear articulation, brief pauses between scenes. The subtitle file follows this script, but its timings must be synchronized to the final generated audio before release.

## 00:00-00:12 — Introduction

Learning without direction can waste time and hide the skills a career goal demands. EduPath turns that challenge into a personalized path from learning to career success.

## 00:12-00:30 — Dashboard

On the dashboard, learners can see their target role, completed tasks, study time, skill-gap closure, and the next best action. Weekly activity and priority gaps bring the plan into focus.

## 00:30-00:50 — Learner profile

Start with a learner profile: current skills, experience, preferred learning style, available study time, and career goal. EduPath uses this information to tailor recommendations. In this demo, Alex is working toward an AI Engineer role.

## 00:50-01:15 — Skill-gap analysis

The skill-gap view compares listed skills and evidence with target-role competencies. Each item shows a current level, required level, priority, and suggested action. These demo-mode insights help the learner decide what to study first.

## 01:15-01:40 — Learning path

Generate a learning path to organize the gaps into learning phases, then review the weekly plan for daily learning, practice, projects, and assessment. The structure turns a broad career goal into manageable work that fits the learner's schedule.

## 01:40-02:05 — Learning assistant

Ask the AI Learning Assistant a focused question, such as how to learn transformer attention and plan a study session. Here, responses are clearly marked as demo-mode guidance because no live LLM provider is configured. Add a provider key in the backend to enable real AI.

## 02:05-02:30 — Practice and progress

Practice Lab generates a question, records the learner's score, and updates progress. A low score can trigger prerequisite review, while task completion and assessments feed the progress summary. Demo information is temporary; this deployment does not report a connected database.

## 02:30-02:50 — Conclusion

EduPath makes learning more focused, measurable, and actionable. Learn smarter. Grow faster. Achieve more. Visit the live product and explore the open-source project on GitHub.
