# 3–5 minute demo

1. Start in Demo Mode.
2. Show the learner profile and target AI Engineer role.
3. Run AI skill-gap analysis.
4. Show mastered/in-progress/missing/weak skills.
5. Generate the adaptive learning path and weekly plan.
6. Complete “Implement Attention Mechanism”.
7. Generate practice and show a question.
8. Generate a portfolio project.
9. Open Progress and explain Measure → Detect → Intervene → Re-plan.
10. Ask the AI Assistant: “What should I learn next?”
11. Generate a progress report.

For live AI, add `LLM_API_KEY`; for persistence, add `DATABASE_URL` and apply the SQL schema.
